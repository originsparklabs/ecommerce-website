# This is a demo storefront for NovaCart.

## Quick start

Open `index.html` in a browser to view the website.

## Files

- `index.html` — storefront layout
- `styles.css` — modern responsive styling
- `script.js` — product catalog and cart interactions

## Features

- Premium storefront hero section
- Responsive product grid
- Category filters
- Cart drawer interaction
- Modern e-commerce design
